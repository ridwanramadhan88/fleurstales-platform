# Batch 1 QA checklist

- Create a size template without a parent image.
- Add Small and Medium child sizes.
- Upload a different guide image for Small and Medium.
- Confirm a size in use cannot be archived and a template in use cannot be deleted.
- Create/edit a product and choose a template size.
- Confirm the variant keeps a stable sizeOptionId and separate size label.
- Confirm each variant can own its own price, product photos, status and flower recipe.
- Confirm existing product-level photos remain intact as a compatibility fallback.
- Confirm legacy variants without sizeOptionId still load and can be edited.
- Do not switch Storefront/cart/order consumption in Batch 1.

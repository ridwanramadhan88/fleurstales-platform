Put a WAV export preset (.epr) in this folder and the panel will use it
automatically, ahead of any other preset it finds on the computer.

Make one in Premiere Pro: File > Export > Media, Format: Waveform Audio,
Audio Codec: Uncompressed, Sample Rate: same as the sequence (e.g. 48000 Hz),
Sample Size: 32-bit float, then Save Preset and copy the .epr here.
